# 来客 PHP 在线客服系统（二开版）安装教程

> 本教程对应你当前仓库中的 **AnniePHP / 来客系** ThinkPHP 5 客服源码（含二维码渠道、黑名单、扫码欢迎语、数据中心、富媒体快捷回复、三端 UI 改版等二开能力）。  
> 若你手头还有旧版《annie 客服系统安装教程》，可对照阅读：**旧版多为「浏览器打开 `install.php` 一键安装」**；本二开包 **`public/install.php` 已禁用**（直接返回 403），请按本文 **手工安装** 流程操作。

## 一、写在前面：你现在该怎么装？

| 方式 | 是否可用 | 说明 |
|------|----------|------|
| 浏览器访问 `/install.php` 一键安装 | **不可用** | 文件开头已 `403` 退出，避免误装与安全隐患。 |
| **宝塔 + 导入 SQL + 改配置 + 启动 ymwl_pusher** | **推荐（本文）** | 与生产一致、可控、可重复。 |
| 从旧服务器整站迁移 | 可用 | 拷贝代码 + 数据库 dump + 同步 `index.php` / `ymwl_pusher/config.php` / 上传目录。 |

**你需要准备：** 一台 Linux 服务器（或本地虚拟机）、已安装 **宝塔面板**、一个域名（测试子域即可）、MySQL 空库或迁移库。

下文把解压后的源码根目录记为 **`$ROOT`**（该目录下应能直接看到 `application/`、`config/`、`public/`、`ymwl_pusher/` 等文件夹）。

## 二、环境要求（与旧教程一致项 + 二开补充）

- **系统**：CentOS 7+ / Ubuntu 18+ 等 x64 Linux（宝塔常用镜像即可）。  
- **Web**：Nginx。  
- **PHP**：建议 **7.4**（7.2～7.4 较稳；**勿盲目上 PHP 8**，ThinkPHP 5.0 与部分依赖易不兼容）。  
- **PHP 扩展（网站 + CLI）**：`curl`、`mbstring`、`pdo_mysql`、`json`、`fileinfo`、`openssl`、`gd`；运行 **Workerman** 的 CLI 还需 **`pcntl`、`posix`**（宝塔「禁用函数」里若禁用了 `pcntl_*` / `posix_*`，`ymwl_pusher` 会起不来）。  
- **MySQL**：5.7+ 或 MariaDB 10+，字符集建议 **utf8mb4**。  
- **Composer**：若上传包内 **`vendor` 不完整**，在 `$ROOT` 执行 `composer install --no-dev`（以项目 `composer.lock` 为准）。

---

## 三、宝塔：创建网站（对应旧教程「建站点」）

1. 登录宝塔 → **网站** → **添加站点**。  
2. **域名**：填写你的测试域名，例如 `kf-test.example.com`。  
3. **根目录**：选到 **`$ROOT/public`**（必须指向 **`public`**，不要指到 `$ROOT` 本身）。  
4. **数据库**：勾选创建 MySQL 数据库，记下库名、用户名、密码。  
5. **PHP 版本**：选 7.4（或 7.2/7.3）。  
6. **伪静态**：选择 **thinkphp**（或复制仓库 `deploy/nginx_thinkphp.conf` 里规则到站点配置）。  
7. （建议）**SSL**：申请 Let’s Encrypt，后面测 **HTTPS + WSS** 更贴近正式环境。

---

## 四、上传源码

1. 将本地二开整包上传到服务器，例如 `/www/wwwroot/kf-test/`，解压后得到 `$ROOT`。  
2. 确认存在 **`$ROOT/public/index.php`**。  
   - 若压缩包里没有（常被忽略未打包）：从**已能运行的同版本环境**复制一份 `public/index.php`，或对照 **`public/install.php` 里「生成 index.php」的模板**（搜索 `file_put_contents('index.php'`）手工生成，保证其中的 **`app_key`、`app_secret`、`app_id`、`whost`、`wport`、`ahost`、`aport`、`domain`、`registToken`、`YMWL_SALT`** 等与下文 **`ymwl_pusher/config.php`** 一致。  
3. 确认 **`$ROOT/ymwl_pusher/vendor`** 存在且完整。

---

## 五、配置数据库连接

编辑 **`$ROOT/config/database.php`**：

- `hostname`：一般为 `127.0.0.1` 或宝塔面板显示的 MySQL 地址。  
- `database` / `username` / `password`：填宝塔创建的数据库信息。  
- `prefix`：保持 **`wolive_`**（与 `install/data.sql` 一致）。

保存后，若站点曾生成过配置缓存，可清空 **`$ROOT/runtime/cache`** 再访问。

---

## 六、导入 SQL（二开版顺序，替代网页安装里的「执行 SQL」）

在 **phpMyAdmin** 或 SSH 里选中你的库，**按顺序**导入（路径均在 `$ROOT/install/` 下）：

| 顺序 | 文件 | 说明 |
|:----:|------|------|
| 1 | `data.sql` | **仅空库**。含 `DROP TABLE`，会清空重建基础表。 |
| 2 | `qr_channel_mvp.sql` | 二维码渠道、扫码日志、黑名单、`visiter` 扩展字段等。 |
| 3 | `ip_blacklist_extend.sql` | 黑名单扩展列；已存在则忽略报错。 |
| 4 | `scan_welcome.sql` | 扫码欢迎语；列已存在则忽略报错。 |
| 5 | `rich_reply.sql` | 富媒体表；会删表重建，**注意已有数据时勿乱执行**。 |
| 6 | `rich_reply_phase2.sql` | 富媒体增量；与上一步字段重复时报错可忽略。 |

**可选校验**：`qr_channel_mvp_check.sql` 只做 `SELECT` 检查，不改数据。

**不要执行**：`uninstall.sql`（卸载用）。

> **从旧版升级**：不要用 `data.sql` 覆盖生产库；只执行尚未执行过的增量脚本，或 mysqldump 恢复后再补增量。

## 七、配置 Pusher / WebSocket（替代安装向导里填的那几项）

本系统实时聊天依赖 **Workerman：`ymwl_pusher`**，浏览器连 **WebSocket 端口**，PHP 后端通过 **HTTP API** 调本机 Pusher。

### 7.1 编辑 `ymwl_pusher/config.php`

- **`$domain`**：与后台业务域名一致，一般带协议，如 `https://kf-test.example.com`（与安装向导里「站点域名」同类）。  
- **`$app_key` / `$app_secret` / `$app_id`**：与 **`public/index.php`** 里同名 **define** 完全一致。  
- **`$websocket_port`**：浏览器连接的 WS 端口，默认常见为 **9090**（可按需改，与安全组一致）。  
- **`$api_port`**：PHP 调 Pusher 的端口，默认常见 **2080**；二开版 **`start.php` 已固定 API 只监听 `127.0.0.1`**，**勿对公网放行该端口**。

### 7.2 编辑 `public/index.php`（与上一步一致）

确保 `define('whost',…)`、`define('wport',…)`、`define('ahost',…)`、`define('aport',…)` 等与 `config.php`、防火墙策略一致。  
站点启用 **HTTPS** 后，通常 **`whost` 要改为 `wss://` 形式**（与前端 Pusher 客户端一致）；若使用 WSS 证书，按 **`ymwl_pusher/start.php`** 内注释配置证书路径。

## 八、目录权限（对应旧教程「runtime、upload 可写」）

在 SSH 中（将 `$ROOT` 换成实际路径）：

```bash
cd /www/wwwroot/你的站点上级   # 若 deploy 与 $ROOT 同级
export PROJECT_ROOT=/www/wwwroot/kf-test
sudo OWNER=www DATA_GROUP=www bash deploy/fix_permissions.sh
```

或手工：`runtime/`、`public/upload/`、`public/uploads/` 对 PHP 运行用户（多为 `www`）**可写**。

## 九、启动 `ymwl_pusher`

```bash
export PROJECT_ROOT=/www/wwwroot/kf-test
bash deploy/start_pusher.sh
```

失败时检查：**CLI 的 pcntl/posix**、`disable_functions`、端口占用。也可用：

```bash
cd $ROOT/ymwl_pusher
php start.php restart -d
php start.php status
```

正式环境建议用 **Supervisor** 或宝塔「进程守护」防止异常退出。

## 十、防火墙与安全组

- **放行**：`80`、`443`、**WebSocket 端口**（如 `9090`）。  
- **不要放行**：Pusher **API 端口**（如 `2080`），应仅 **127.0.0.1** 本机访问。  
- MySQL **3306** 默认不对公网开放。

---

## 十一、安装完成怎么验收？

1. 浏览器打开：`https://你的域名/` 或后台登录地址（按你环境路由，一般为 `/admin/...` 登录页，以实际为准）。  
2. 使用数据库 **`data.sql`** 里自带的商户/管理员账号登录；若密码与官方 dump 一致，**登录后立即修改密码**。  
3. 打开 **客户咨询 / 聊天页**，确认能连上 WebSocket（浏览器 F12 → Network → WS 无长期失败）。  
4. 抽测：**发消息、二维码渠道、黑名单、欢迎语、富媒体快捷回复、数据中心**。

服务器自检可执行：

```bash
bash deploy/check_env.sh
```

## 十二、常见问题（FAQ）

**Q1：打开站点 500 / 空白**  
检查 `runtime/log`、Nginx 错误日志；多为 `database.php` 错误、`index.php` 缺失、`runtime` 不可写。

**Q2：聊天不实时、一直转圈**  
未启动 `ymwl_pusher`、防火墙未放行 WS 端口、`whost`/`wport` 与证书（WSS）不一致、`app_key` 与 `config.php` 不一致。

**Q3：install.php 能打开吗？**  
不能用于安装；返回 403 为预期行为。请用本文流程。

**Q4：和旧 annie 教程里「设置运行目录」不一致？**  
本系统必须是 **`public`** 作为网站运行目录，与 ThinkPHP 官方一致。
