# 打包上传说明（上传前请看）

## 要打哪个文件夹

请压缩 **整个项目根目录**（内含 `public/`、`application/`、`config/`、`ymwl_pusher/`、`install/`、`vendor/`、`docs/`、`deploy/` 等的那一层）。

在本地仓库中，该目录一般为：`最新版来客客服带预知`（若你已改名为 `kefu`，则压缩 `kefu` 即可）。

**不要**只压缩 `public`，否则 ThinkPHP 与 Pusher 无法运行。

## 已为你整理好的内容

1. **`docs/`、`deploy/`** 已移到项目根目录下，与网站代码同级，**一次打包全部带上**。  
2. **`客服系统源码审计与二开设计报告.md`** 已放入 **`docs/`**，便于随包交付。  
3. **`runtime/cache`、`runtime/temp`** 下缓存已清空，减小压缩包体积；服务器上首次访问会重新生成。

## 压缩时建议排除（可选）

若使用 7-Zip / WinRAR，可手工排除下列项以进一步缩小包（**排除前请确认不需要**）：

| 路径 | 说明 |
|------|------|
| `backup/**/*.bak` | 历史改版的 `.bak` 备份，上传非必须 |
| `.git/` | 若项目在 Git 下，一般不上传服务器 |
| `runtime/log/*` | 本地调试日志，可不上传（保留 `runtime/log` 空目录亦可） |

**必须保留**：`vendor/`（除非你在服务器上会重新 `composer install`）、`ymwl_pusher/vendor/`、`install/*.sql`、`public/`（含 `index.php` 若存在）。

## 上传到服务器后

1. 解压到站点目录，宝塔 **运行目录** 设为 **`/public`**。  
2. 阅读 **`docs/来客客服系统安装教程.md`** 与 **`docs/新服务器测试部署清单.md`**。  
3. 在项目根执行：`bash deploy/fix_permissions.sh`、`bash deploy/check_env.sh`、`bash deploy/start_pusher.sh`（Linux 下）。
